# Cutscene template

Build one causal transition that changes what a character can do, knows, wants, or must confront in play.

- Enter from the supplied gameplay state; preserve location, positions, facing, carried objects, relationships, and active goal. Establish only missing facts needed for the change.
- Show trigger or opportunity → visible response → consequence → persistent new state. Keep the immediate goal or outcome stakes observable.
- Each cut reveals one action, reaction, decision, or exact line. Show cause before reaction; preserve screen direction and geography.
- Pair dialogue with visible behavior instead of plot summary. Keep identity, props, speaker IDs, and reference roles stable.
- End with a playable handoff: a route, threat, object, relationship, or requested state is ready for the next action.
- Slow only the emphasized action interval; show its consequence at normal speed unless requested otherwise.
