# Ref2VA

Use when one or more references supply reusable content, frames, motion, timing, or audio.

- Set `mode` to `reference_to_video`; use only the applicable top-level reference path arrays.
- Assign every role from inspection or explicit user statements. Ask when an opaque material has no usable role; never infer from its path.
- Distinguish reusable visible content, concrete frame anchors, source-video editing or motion, and copied or referenced audio. Do not make one reference responsible for an unrelated role.
- When a reference supplies appearance only, retain only the observed identity, body, face, hair, clothing, or equipment needed by the request; explicitly exclude its background, lighting, pose, and framing. List only applicable attributes.
- Use a reference video's synchronized track only when that audio is explicitly needed; the presence of sound in a video does not automatically make it an audio reference.
- Keep every role stable and state the exact shot or point where it takes effect.
- Follow the selected model profile for labels, definitions, relationship markers, section order, and reference limits.
