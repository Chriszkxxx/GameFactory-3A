# T2VA

Use when no image, video, or audio material is supplied.

- Set `mode` to `text_to_video` and add no material-path field.
- Build the complete audiovisual timeline from the user's intent.
- For recurring subjects with no reference, define a minimal stable cast at first appearance: exact count when continuity depends on it, shared appearance for a group, and one visible discriminator only when roles must differ. Reuse those roles instead of redesigning them after a cut.
- Establish style, composition, subject, and environment in Shot 1, then describe actions and resulting states in playback order.
- Use later shots only when they add necessary information and fit inside `duration_sec`.
- Follow the selected model profile for the exact prompt structure.
