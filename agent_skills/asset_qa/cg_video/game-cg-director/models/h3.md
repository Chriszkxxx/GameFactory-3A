# H3 model profile

```json machine-checks
{"model":"h3","min_duration_sec":4,"max_duration_sec":15,"max_reference_images":9,"max_reference_videos":3,"max_reference_audio":3,"max_reference_files":12}
```

## Limits

- Output: 4–15 seconds. Base modes cover text-only, first frame, or first-and-last frames; this skill never treats one image as a last frame.
- Ref2VA: at most 9 images, 3 videos, 3 audio clips, and 12 files total. Each video/audio clip and each modality's combined duration are 2–15 and at most 15 seconds respectively; paths alone cannot verify media length.
- H3-Context-IR is hosted preprocessing/orchestration, not an open-source local implementation.

## Language and timeline grammar

Write every section in English. Preserve original language only in dialogue/lyric tags or quoted visible text.

- Start with `[Shot 1]` without a timestamp. Every later shot starts `[Shot N] At MM:SS.mmm,`; use sequential numbers and strictly increasing cut times below `duration_sec`.
- Give vocal sources stable `(S1)`, `(S2)` IDs. Inside `<d>[Language] ...</d>`, put only the language tag and exact words; keep speaker description, ID, action, and delivery outside.
- Put visible text in English double quotation marks without translation. Exclude model/provider names from the prompt.

## T2VA, I2VA, and FL2VA

Put these exact fields in `prompt` in this order:

```text
integrated_multimodal_description: ...
overall_soundscape: ...
non_diegetic_music: ...
```

`overall_soundscape`: 1–4 English sentences for ambience, physical actions, and non-verbal human sounds; never repeat dialogue. Use `N/A` only for requested complete silence. `non_diegetic_music`: 1–3 English sentences for instrumentation, tempo, rhythm, and audible dynamic change; use `N/A` when no audience-only music is requested.

T2VA begins directly with `integrated_multimodal_description:` and uses no reference label.

For I2VA, begin with this exact line, followed by one blank line:

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

This binds the first frame. Repeat `<Picture 1>` in the timeline only to remove ambiguity.

For FL2VA, begin with this exact line, followed by one blank line:

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

Replace `N` with the final shot number and `S.SS` with `duration_sec` to two decimals. Use `<Picture 1>` and `<Picture 2>` in the timeline for the endpoints.

## Ref2VA

Put these exact fields in `prompt` in this order:

```text
subject_definitions: ...
summary: ...
retention_analysis: ...
detailed_description: ...
overall_soundscape: ...
non_diegetic_music: ...
```

- Labels: `<Subject N>` reusable visible content; `<Picture N>` concrete frame/shot anchor; `<Video N>` source editing, continuation, camera movement, cuts, rhythm, or timing; `<Audio N>` copied/referenced audio. Number each type independently and contiguously; keep meanings stable and define every used label.
- A reference video's enabled synchronized track may get an `<Audio N>` label but does not create one automatically. Define its role/provenance separately from any audio file.
- Give each primary label one `subject_definitions` line. A picture used only to source a subject may appear inside that subject's definition instead.
- Start `summary` with applicable task types in brackets: `keyframe completion`, `reference generation`, `video editing`, `video continuation`, `audio reuse`, or `audio reference`; join multiples with ` + `.
- Give each primary definition one matching `retention_analysis` line. Visual markers: `fully_preserved`, `partially_preserved`, `attribute_transfer`, `weak_reference`. Audio: `fully_copy`, `partially_copy`, `reference`, `weak_reference`.
- In `detailed_description`, state where every reference responsibility takes effect. Keep dialogue out of both sound fields; apply base-mode sound lengths and content rules.
