# UI Generation Requirements — gameForge_rpg

## Overview
Generate the complete in-game UI for the UE5 third-person exploration RPG.
The UI receives the finalized Mechanic artifact, game design document, and
engine context. Output is engine-native UE5 UMG widgets.

## Engine
- **Engine**: Unreal Engine 5
- **UI Target**: engine_runtime (UE5 UMG widgets)
- **Module Name**: RPGGameUI

## UI Screens

### 1. RPGHUD (Main In-Game HUD)

#### Interaction Prompt
- **Position**: Center-bottom of screen, above any dialogue
- **Content**: "Press E to interact"
- **Behavior**: Appears when player is near an interactable object (NPC, chest, tablet)
- **Context-aware**: Shows target name ("Talk to NPC", "Open Chest", "Read Stone Tablet")
- **Style**: Semi-transparent background, white text, subtle fade in/out

#### Progress Tracker
- **Position**: Top-right of screen
- **Content**: "Treasure Chests: X/3"
- **Behavior**: Updates when a chest is opened
- **Style**: Small icon + text, semi-transparent

#### Objective Reminder
- **Position**: Top-left of screen (small, unobtrusive)
- **Content**: "Find 3 treasure chests"
- **Behavior**: Always visible during gameplay

### 2. DialogueBox
- **Position**: Bottom of screen, covering ~30% of screen height
- **Content**: NPC name + dialogue text
- **Behavior**: Appears when talking to NPC, dismiss on E or click
- **Style**: Semi-transparent dark background, white text, NPC portrait optional
- **Text**: Typewriter effect (optional)

### 3. StoneTabletOverlay
- **Position**: Center of screen, full-screen overlay
- **Content**: Stone tablet text: "This area holds three treasure chests. Go explore and find them."
- **Behavior**: Appears when reading tablet (press E), dismiss on E or Esc
- **Style**: Darkened background, centered text on tablet texture

### 4. ChestOpenPopup
- **Position**: Center of screen
- **Content**: "You found a treasure!"
- **Behavior**: Appears for 2-3 seconds when chest is opened, then fades
- **Style**: Golden glow, celebratory

### 5. GameCompleteScreen
- **Position**: Full-screen overlay
- **Content**: "All Treasures Found!" + "Press ENTER to Restart"
- **Behavior**: Triggered when all 3 chests are opened
- **Style**: Bright, celebratory background

### 6. PauseMenu
- **Position**: Full-screen overlay
- **Content**: "Paused" + "Press Esc to Resume" + "Press Enter to Restart"
- **Behavior**: Triggered by Esc key

## State Bindings
- chests_opened — number of chests opened (0-3)
- total_chests — total chests (3)
- current_interaction — name of nearby interactable ("NPC", "Chest", "Stone Tablet", null)
- is_dialogue_active — true when dialogue is showing
- dialogue_text — current dialogue text
- dialogue_speaker — current NPC name
- is_tablet_active — true when reading tablet
- game_state — "playing", "complete", "paused"
- is_near_interactable — true when near any interactable

## Event Bindings
- on_interactable_entered(target) — show interaction prompt
- on_interactable_exited() — hide interaction prompt
- on_dialogue_start(npc_name, text) — show dialogue box
- on_dialogue_end() — hide dialogue box
- on_tablet_read(text) — show tablet overlay
- on_chest_opened(chest_id) — show chest popup, update progress
- on_game_complete() — show game complete screen
- on_pause() — show pause menu
- on_resume() — hide pause menu

## Command Bindings
- interact — trigger interaction
- dismiss_dialogue — close dialogue
- reset_game — restart from beginning

## Viewports
- 1920×1080 (primary, 16:9 landscape)
- 1280×720 (secondary)

## Acceptance Criteria
- Interaction prompt appears when near interactable objects
- Interaction prompt shows context ("Talk to NPC", "Open Chest", "Read Stone Tablet")
- Progress tracker shows "X/3" and updates on chest open
- Objective reminder visible during gameplay
- Dialogue box appears when talking to NPC
- Dialogue shows correct NPC text
- Stone tablet overlay shows correct message
- Chest open popup appears on chest open
- Game complete screen shows when all 3 chests opened
- Pause menu works (Esc to pause/resume)
- Restart resets all UI elements

## Forbidden UI
- No 3D world-space UI
- No mobile touch controls
- No combat UI (no health bars, no weapon wheel)
- No microtransactions
