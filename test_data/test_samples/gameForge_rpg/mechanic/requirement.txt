# Mechanic Code Generation Requirements — gameForge_rpg

## Overview
Generate complete UE5 gameplay logic (Blueprints or C++ module) for the
third-person exploration RPG. The generated code receives character assets,
animation clips, scene, and prop objects as input.

## Engine
- **Engine**: Unreal Engine 5
- **Module Name**: RPGGameplay

## Input Assets
- **Player Model**: explorer character (generated via Meshy API)
- **NPC Models**: 3 different NPC characters (generated via Meshy API)
- **Bat Models**: bat creature (generated via Meshy API)
- **Prop Models**: stone_tablet, treasure_chest (generated via Meshy API)
- **Animation Clips**:
  - Player: idle, walk, run, interact (4 clips)
  - NPC: idle, wander (2 clips each, 6 total)
  - Bat: fly (1 clip)
- **Scene**: Imported open-source countryside map
- **Engine API Docs**: agent_skills/engine_context/ue5_api.md

## Required Systems

### 1. RPGPlayerController
Third-person movement and interaction.
- WASD movement
- Shift to sprint
- Third-person camera follows player
- E key triggers interaction with nearby interactable objects
- Smooth movement, no combat

### 2. RPGInteractSystem
Interaction detection and routing.
- Detects nearby interactable objects (NPC, chest, tablet)
- Shows interaction prompt ("Press E to interact")
- Routes interaction to correct handler (dialogue, chest open, tablet read)
- Only one interaction at a time

### 3. RPGDialogueSystem
NPC dialogue display.
- When interacting with NPC, show dialogue text box
- NPC-specific dialogue lines:
  - NPC 1: "I saw something glowing near the old tree. Could be a treasure chest."
  - NPC 2: "There's a strange chest by the river. I'd check it out if I were you."
  - NPC 3: "A treasure chest lies hidden near the ruins. Seek it out!"
- Dialogue box appears at bottom of screen
- Press E or click to dismiss dialogue

### 4. TreasureChest
Chest interaction logic.
- Chest starts closed
- Press E when near to open
- Plays chest open animation
- Shows reward message ("You found a treasure!")
- Marks chest as opened (cannot reopen)
- Notifies RPGGameProgress

### 5. RPGGameProgress
Progress tracking and win condition.
- Tracks number of chests opened (0-3)
- When all 3 chests opened, trigger game complete
- Provides progress data to UI (X/3)
- Win state: "All treasures found!"

### 6. RPGCameraController
Third-person follow camera.
- Follows player from behind at elevated angle
- Smooth interpolation
- No jitter
- Camera collision with environment

### 7. BatFlock
Bat ambient behavior.
- Bats spawn at each treasure chest location
- Fly in circular patterns around chest area
- Non-hostile, cannot be interacted with
- Simple wing flap animation loop

### 8. NPCWander
NPC idle and wander behavior.
- Each NPC stays near its assigned chest location
- Alternates between idle and slow walking
- Wanders within a small radius (~5 meters)
- Turns to face player during dialogue

## Controls

| Action | Key |
|--------|-----|
| Move | WASD |
| Sprint | Shift |
| Interact | E |
| Pause | Esc |

## Acceptance Criteria
- Compile success
- Player spawns in third-person view
- Camera follows player smoothly
- WASD moves player, Shift sprints
- Stone tablet placed near spawn, readable (press E)
- Stone tablet shows "three treasure chests" message
- 3 treasure chests at different locations
- Each chest has an NPC wandering nearby
- NPC dialogue works (press E, text appears)
- NPC dialogue hints about nearby treasure
- Bats visible flying near each chest
- Chest opens on E press with animation
- Progress tracker updates (X/3)
- All 3 chests → game complete screen
- Interaction prompt appears near interactables
- Restart works from complete screen

## Validation Checks
1. compile_success — Game compiles without errors
2. player_can_move — WASD movement works
3. camera_follows — Third-person camera follows player
4. tablet_interactable — Stone tablet can be read
5. tablet_text — Displays correct message
6. chests_placed — 3 chests at different locations
7. npc_present — NPC near each chest
8. npc_dialogue — Talking to NPC shows dialogue
9. bats_visible — Bats flying near chests
10. chest_opens — Chest opens on E with animation
11. progress_tracks — Progress updates correctly
12. game_complete — All 3 chests triggers win
13. interaction_prompt — Prompt appears near interactables
