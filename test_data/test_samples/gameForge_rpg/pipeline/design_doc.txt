# gameForge_rpg — Game Design Brief

## Page 1: Concept & Gameplay

### Game Vision
gameForge_rpg is a calm third-person exploration RPG built on Unreal Engine 5,
inspired by Zelda Breath of the Wild's sense of discovery. The player explores
a countryside map, reads a mysterious stone tablet, talks to wandering NPCs for
hints, and discovers three hidden treasure chests. There is no combat — the
focus is on exploration, interaction, and atmosphere.

### Core Gameplay Loop
Launch → Spawn → Read Stone Tablet → Explore → Find NPC → Dialogue →
Find Chest → Open → Progress → Next Chest → All 3 Found → Complete → Restart

### Camera & Perspective
Third-person camera following the player from behind at an elevated angle.
Smooth interpolation, camera collision with environment.

### Characters

**Player — Explorer (探索者)**
A humanoid character exploring the countryside. Can walk, sprint, and interact
with objects and NPCs by pressing E. No combat abilities.

**NPCs (3 different characters)**
Three distinct NPCs, each wandering near a treasure chest location. When
approached and E is pressed, they provide a hint about the nearby treasure:
- NPC 1 (near old tree): "I saw something glowing near the old tree. Could be a treasure chest."
- NPC 2 (near river): "There's a strange chest by the river. I'd check it out if I were you."
- NPC 3 (near ruins): "A treasure chest lies hidden near the ruins. Seek it out!"

**Bats (ambient creatures)**
Bats fly in circular patterns near each treasure chest. Non-hostile, purely
atmospheric. Generated 3D models with simple wing-flap animation.

### Objects

**Stone Tablet (石碑)**
A generated 3D stone tablet placed near the player spawn point. Inscribed
text: "This area holds three treasure chests. Go explore and find them."
Press E to read.

**Treasure Chests (宝箱) × 3**
Three chests scattered across the map at different locations (near an old tree,
by a river, near ruins). Each can be opened by pressing E. Opening plays an
animation and shows a reward message. Opening all 3 completes the game.

### Scene
Imported open-source countryside map. Open fields, trees, hills, paths.
Natural daylight, bright and calm atmosphere. Three treasure locations spread
across the map with NPCs and bats at each.

## Page 2: Technical & Production

### Engine & Architecture
- **Engine**: Unreal Engine 5
- **Code Module**: RPGGameplay (Blueprints or C++)
- **UI Module**: RPGGameUI (UMG widgets)

### AI Asset Generation Pipeline
1. **3D Objects**: Meshy API → player, 3 NPCs, bat, stone tablet, treasure chest models
2. **Motions**: MoMask → BVH → retarget → animation FBX
   - Player: idle, walk, run, interact (4 clips)
   - NPC: idle, wander (2 clips each, 6 total)
   - Bat: fly (1 clip)
3. **Scene**: Imported open-source countryside map
4. **Audio**: Seed Audio API → ambient nature sounds, NPC voice (optional)

### Game Mechanics (8 Systems)
1. RPGPlayerController — movement, sprint, interaction trigger
2. RPGInteractSystem — nearby interactable detection, prompt display
3. RPGDialogueSystem — NPC dialogue text display
4. TreasureChest — chest open logic, reward, one-time use
5. RPGGameProgress — chest tracking (0-3), win condition
6. RPGCameraController — third-person follow camera
7. BatFlock — bat spawning and circling flight
8. NPCWander — NPC idle and wander behavior

### UI Design
- Interaction prompt (bottom-center): "Press E to interact"
- Progress tracker (top-right): "Treasure Chests: X/3"
- Objective reminder (top-left): "Find 3 treasure chests"
- Dialogue box (bottom): NPC name + dialogue text
- Stone tablet overlay (full-screen): tablet text
- Chest open popup (center): "You found a treasure!"
- Game complete: "All Treasures Found!" + restart prompt
- Pause menu: Esc

### Controls
| Action | Key |
|--------|-----|
| Move | WASD |
| Sprint | Shift |
| Interact | E |
| Pause | Esc |

### Acceptance Criteria (13 checks)
Launch (1), Movement (2), Interaction (4), Chests (3), UI (3)

Find Chest → Open → Progress → Next Chest → All 3 Found → Complete → Restart
