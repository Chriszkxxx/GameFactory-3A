# UI Generation Requirements — gameD_forest_adventure

## 概述

本目录包含 gameD_forest_adventure（自由探索 ARPG）的 UI 界面生成任务。
通过 LLM Agent 调用 Unity 工具链自动生成 UI Canvas、面板、文本、图片等组件。

---

## 生成方式

Agent 接收设计规格和资产清单后，调用 Unity UI 工具生成 UI prefab 和绑定脚本。

---

## UI 元素清单

### 1. 生命条 (demoForest_052)
- **位置**: 左下角
- **样式**: 条状血条，带心形图标，受击时闪红
- **数据源**: HealthSystem (player current_hp / max_hp)
- **响应**: 受击时血条减少 + 红色闪烁动画
- **分辨率**: 1920×1080 设计，支持自适应缩放

### 2. 弓箭数 (demoForest_053)
- **位置**: 右下角
- **样式**: 箭矢图标 + 数字 "当前/最大"
- **数据源**: BowAimingSystem (current_arrows / max_arrows)
- **响应**: 射箭时数字减少，拾取补给时增加
- **分辨率**: 1920×1080 设计，支持自适应缩放

### 3. 准星 (demoForest_054)
- **位置**: 屏幕中央
- **样式**: 十字准星，金色描边
- **数据源**: BowAimingSystem (is_aiming)
- **响应**: 仅在瞄准模式下显示，非瞄准时隐藏
- **分辨率**: 1920×1080 设计

### 4. 小地图 (demoForest_055)
- **位置**: 右上角
- **样式**: 圆形或方形简化小地图
- **数据源**: 玩家位置、宝箱位置、怪物位置、场景边界
- **显示内容**: 玩家（金色点）、宝箱（白色图标）、怪物（红色点）
- **响应**: 实时更新所有标记位置
- **分辨率**: 1920×1080 设计，支持自适应缩放

### 5. 击杀计数 (demoForest_056)
- **位置**: 右上角（小地图下方）
- **样式**: "击杀: N" 文字 + 骷髅图标
- **数据源**: EnemyAI / EnemySpawner (kill_count)
- **响应**: 每次击杀怪物时数字增加 + 弹出动画
- **分辨率**: 1920×1080 设计

### 6. 交互提示 (demoForest_057)
- **位置**: 屏幕中下方（或目标物体上方）
- **样式**: 半透明背景框 + "按 E 互动" 文字
- **数据源**: TreasureChest (is_player_near)
- **响应**: 靠近宝箱时淡入显示，离开时淡出隐藏
- **分辨率**: 1920×1080 设计

---

## 技术要求

1. 所有 UI 使用 Unity UGUI (Canvas + RectTransform) 系统
2. Canvas 设置为 Screen Space - Overlay，CanvasScaler 为 Scale With Screen Size
3. 参考分辨率: 1920×1080
4. UI 文字使用通用无衬线字体
5. 所有 UI 元素需要响应式布局，适配不同分辨率
6. UI 脚本需通过事件订阅（C# event/delegate）与游戏逻辑解耦
