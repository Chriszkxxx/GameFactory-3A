# Game Design Brief — Forest Adventure (gameD_forest_adventure)

## Page 1: Game Overview & Core Loop

### Game Title
Forest Adventure — 弓手林中猎杀

### Game ID
gameD_forest_adventure

### Genre
Third-person Open-world Action RPG (自由探索 ARPG)

### Visual Reference
The Legend of Zelda: Breath of the Wild — but with a more realistic, grounded
aesthetic. Dense fantasy forest with volumetric god rays, mossy terrain, and
magical combat effects.

### Engine
Unity3D 2022.3 LTS (Universal Render Pipeline)

---

### Core Gameplay Loop

```
Launch → Explore Forest → Find Enemy → Combat (Melee + Ranged)
  → Kill Enemy → Find Treasure Chest → Get Reward → Continue Exploring
```

The player embodies a young archer hero in a green hooded cloak, exploring a
dense fantasy forest. The game features dual combat modes: melee sword strikes
and ranged bow attacks with magical light arrows. Enemies include flying
demonic bats that dive-bomb the player and ground-based forest goblins that
chase with wooden clubs. Treasure chests are scattered throughout the forest,
offering rewards (arrow refills, health restoration) when opened.

### Player Character
- Young archer hero with green hooded cloak and leather adventurer hat
- Carries a staff/bow on back and a sword at the waist
- Wears leather chest armor and boots
- 9 generated motions: idle, walk, run, jump, sword_swing_1,
  sword_swing_2, ranged_attack, hit_react, death

### Enemies
1. **Demonic Bat (Flying)**: 2m wingspan, dark purple skin, red glowing eyes,
   fangs. AI: flies toward player and uses procedural flight and dive motion.
2. **Forest Goblin (Ground)**: Small, green skin, wooden club, rags.
   AI: walks toward player on NavMesh, overhead club smash. 5 motions.

### Combat System
- **Melee**: Left-click triggers sword swings (horizontal slash / vertical chop).
  Silver-white arc VFX trail. Hit detection via overlap sphere.
- **Ranged**: Hold right-click to enter aim mode (camera zooms to over-shoulder,
  crosshair appears). Release to fire a golden light arrow with particle trail.
  Arrow travels as projectile, collides with enemies, deals damage, spawns
  golden burst VFX on hit.
- **Weapon Switch**: Press Q to toggle between sword and bow modes.

### Treasure System
- 3-5 treasure chests placed at varying locations in the forest
- Proximity detection shows "Press E to Interact" prompt
- Press E: plays chest open animation + golden light pillar VFX + particle spread
- Rewards: arrow refills, health restoration, kill count tracking

## Page 2: Scene, Audio, UI & Technical Specs

### Scene Design
- **Environment**: Dense fantasy forest with towering trees forming a canopy
  that filters sunlight into dramatic god rays (Tyndall effect)
- **Terrain**: Grass, fallen leaves, moss coverage with natural transitions
- **Water**: Small stream with stepping stones
- **Foliage**: Scattered mushrooms, bushes, rocks
- **Lighting**: URP Volumetric Fog for realistic light shafts through canopy.
  Directional sunlight at low angle for piercing beams. Green and warm gold
  color palette.
- **Distant**: Mountain silhouettes for depth perception
- **Game Elements**: 3-5 treasure chests, 8 enemy spawn points, NavMesh baked
  for ground enemy pathfinding

### Audio Design
- **Ambient**: Forest soundscape (birdsong, rustling leaves, wind, distant
  stream) — seamless 10s loop
- **Combat SFX**: Sword swing whoosh, bowstring draw/release, arrow launch
  hum, arrow impact burst, player hit grunt
- **Enemy SFX**: Bat death screech (purple dissolve), goblin death groan
  (green dissolve)
- **Interaction SFX**: Chest open (creak + magical chime), footsteps (leaf
  crunch), jump/land, item pickup chime

### UI Design
| Element | Position | Description |
|---------|----------|-------------|
| Health Bar | Bottom-left | Heart icon + horizontal bar, red flash on hit |
| Arrow Count | Bottom-right | Arrow icon + "current/max" number |
| Crosshair | Center | Golden cross reticle, visible only in aim mode |
| Minimap | Top-right | Player (gold), chests (white), enemies (red) |
| Kill Count | Top-right (below minimap) | Skull icon + count, pop animation |
| Interaction Prompt | Center-bottom | "Press E to Interact" with E key icon |

### Controls
| Action | Key |
|--------|-----|
| Move | WASD |
| Jump | Space |
| Melee Attack | Left Mouse Button |
| Aim Bow | Right Mouse Button (hold) |
| Fire Arrow | Release Right Mouse Button |
| Interact | E |
| Switch Weapon | Q |

### Camera
- Third-person follow camera with smooth damping
- Aim mode: zooms to over-shoulder perspective
- Mouse look controls horizontal camera rotation

### Technical Architecture (Mechanic Classes)
1. AdventurePlayerController — movement, jump, weapon state
2. CombatSystem — melee + ranged combat coordination
3. BowAimingSystem — aim mode, crosshair, arrow firing
4. ProjectileSystem — light arrow physics, collision, damage
5. EnemyAI (BatAI + GoblinAI) — chase, attack, hit/death behaviors
6. EnemySpawner — timed respawning, population cap
7. TreasureChest — interaction, rewards, VFX
8. HealthSystem — HP management, death handling, UI binding
9. AdventureCameraController — third-person follow + aim zoom

- [x] Forest scene loads with volumetric lighting
- [x] Player spawns with third-person camera
- [x] WASD movement + Space jump with animations

- [x] Bats fly and chase; goblins walk and chase
- [x] Enemies attack, player takes damage, HP decreases
- [x] Enemies respawn over time
- [x] Treasure chests placed, E to open, rewards granted
