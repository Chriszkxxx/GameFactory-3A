# Prepared Racing Track Requirements - gameF_racing

## Source

The first version substitutes an existing local Unity track scene for generated
scene geometry. Task `demoRacing_010` identifies the source project and scene.
The source is never imported directly by the generated game project: it must be
cleaned and materialized as `environment.unitypackage` in the canonical run.

## Environment-Only Export

Keep meshes, renderers, materials, textures, terrain, lights, reflection
probes and useful static colliders. Remove original gameplay scripts, karts,
characters, cameras, UI, event systems and audio listeners. The exported scene
must contain no missing-script components.

## Playability Contract

- A continuous driveable collision surface covers the complete racing route.
- Guard rails and solid scenery block vehicles.
- Four clear start-grid positions do not overlap scenery.
- Ordered checkpoint anchors cover the complete lap.
- A closed waypoint route supports three AI cars.
- The scene loads in Unity 2022.3 URP with materials and lighting intact.

The source asset remains local. Redistribution permission must be verified
before publishing the scene or a build containing it.
