# UI Generation Requirements — gameC_fighting_arena_unity

## Overview
Generate the complete in-game UI for the 3D versus fighting game. The UI is
generated as an outer-Agent task that receives the finalized Mechanic artifact
(gameplay contract), the game design document, and engine context. The output
includes engine-native UI (Unity UGUI/UI Toolkit) and a Browser Play frontend.

## Engine
- **Engine**: Unity3D 2022.3 URP
- **UI Target**: engine_runtime (generates engine-native UI, then Browser Play)
- **Delivery Mode**: engine_native_then_browser_play

## UI Screens

### 1. FightingHUD (Main In-Game HUD)
The primary heads-up display shown during combat.

#### HP Bars
- **Position**: Top-left (P1) and top-right (P2) of the screen
- **Design**: Wide KOF-style horizontal bar with a live character portrait on
  the outer edge, a dark frame, and a clear remaining-health fill
- **Behavior**: Depletes from outer edge inward as HP decreases
- **Visual feedback**: Flashes white briefly when the character takes damage
- **Color**: P1 = warm red/orange, P2 = cool blue/purple
- **Portrait**: P1 face fixed in the extreme top-left corner; P2 face fixed in
  the extreme top-right corner; health bars occupy the highest horizontal row
- **Runtime source**: portrait is rendered from the imported fighter prefab so
  it remains traceable to the benchmark character asset

#### Ultimate Energy Bar
- **Position**: Directly below each HP bar
- **Design**: Thinner horizontal bar, segmented (10 segments)
- **Behavior**: Fills from 0% to 100% as energy accumulates
- **Visual feedback**: Glows/highlights when 100% full, pulsing animation
- **Color**: Warrior = orange-gold, Ninja = cyan-purple

#### Round Indicator
- **Position**: Center top of screen below the timer, without overlapping bars
- **Content**: current round and numeric P1/P2 round-win score
- **Transitions**: "FIGHT!" (large, animated, fades out), "K.O." (dramatic, screen shake)
- **Round pips**: Three small markers per player (best of 5, first to 3)

#### Timer
- **Position**: Center top as the dominant center number
- **Content**: Large countdown number from 99 to 0
- **Behavior**: Turns red and pulses when ≤10 seconds remaining

#### Character Name Plates
- **Position**: Above each HP bar
- **Content**: Character name ("WARRIOR" / "NINJA")
- **Style**: Bold, stylized font with drop shadow

### 2. RoundTransition
- Full-screen overlay between rounds
- Shows round number ("ROUND 2") with dramatic entrance animation
- Brief pause before "FIGHT!" triggers
- Fades to reveal the FightingHUD

### 3. MatchEnd
- Full-screen overlay when match concludes
- Shows winner character portrait and name
- "YOU WIN" / "YOU LOSE" text (or "P1 WINS" / "P2 WINS")
- "Press ENTER to Restart" prompt
- "Press ESC to Quit" prompt
- Background: darkened arena with spotlight on winner

### 4. UltimateCinematic
- Full-screen overlay triggered when ultimate skill activates
- Time freeze effect (desaturation, vignette)
- Character close-up with dynamic camera angle
- Subtitle bar at bottom with character voice line text
- Warrior: "被我的拳头放倒吧！"
- Ninja: "接受你的命运吧"
- VFX particles overlay (fire for warrior, energy for ninja)
- Duration: 2-3 seconds, then fades back to gameplay

## State Bindings (from Mechanic Contract)
- P1_HP, P2_HP — health points (0-100)
- P1_Energy, P2_Energy — ultimate energy (0-100)
- Round_Number — current round (1, 2, 3)
- Timer_Remaining — seconds left (0-99)
- P1_Round_Wins, P2_Round_Wins — rounds won (0-2)
- Match_State — "fighting", "round_end", "match_end"
- P1_State, P2_State — character state ("idle", "attacking", "blocking", "hit", "knockdown", "ultimate")

## Event Bindings (from Mechanic Contract)
- OnDamageTaken(player, amount) — trigger HP bar flash
- OnEnergyChanged(player, amount) — update energy bar
- OnRoundStart(round_number) — show round indicator
- OnFightStart() — show "FIGHT!" text
- OnKO(loser) — show "K.O." text
- OnRoundEnd(winner) — show round transition
- OnMatchEnd(winner) — show match end screen
- OnUltimateActivated(player) — show ultimate cinematic
- OnTimerTick(remaining) — update timer display
- OnTimerLow() — timer turns red

## Command Bindings (from Mechanic Contract)
- RestartMatch() — restart from round 1
- QuitGame() — exit application

## Viewports
- 1920×1080 (primary, 16:9 landscape)
- 1280×720 (secondary, for lower-end displays)

## Acceptance Criteria
- HP bars visible and update in real time
- Both imported-character portraits are visible beside their corresponding bars
- HP bars flash white when character takes damage
- Energy bars fill during combat and highlight when full
- Timer counts down from 99 and turns red at ≤10 seconds
- Round indicator shows correct round number
- "FIGHT!" text appears at round start
- "K.O." text appears on knockout
- Character name plates visible above HP bars
- Round win pips update correctly
- Ultimate cinematic overlay triggers on ultimate activation
- Subtitles display character voice lines during cinematic
- Match end screen shows winner
- "Press ENTER to Restart" appears on match end
- Restart resets all UI elements

## Forbidden UI
- No 3D world-space UI (all UI must be screen-space overlay)
- No mobile touch controls (keyboard/gamepad only)
- No microtransactions or store UI
- No settings menu (focus on gameplay HUD only)
