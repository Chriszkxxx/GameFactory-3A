================================================================================
 Mechanic Code Generation Requirements — gameC_fps_tactical_unity
================================================================================

生成方式: LLM Agent 调用 Unity tools 生成 C# 游戏机制代码
引擎: Unity3D 2022.3 URP
输出: Unity Assembly (C# DLL) + C# 脚本

--------------------------------------------------------------------------------
 需要生成的系统 (Systems to Generate)
--------------------------------------------------------------------------------

1. FPSPlayerController
   - 第一人称移动 (WASD 走、Shift 跑、Space 跳、Ctrl 蹲)
   - 鼠标控制视角 (Mouse Look, pitch + yaw)
   - 角色控制器 (CharacterController) 物理
   - 头部摆动 (head bob) 效果

2. WeaponSystem
   - 武器管理 (射击、换弹、后坐力)
   - 射线检测命中 (Raycast hit detection)
   - 枪口火焰特效 (Muzzle flash VFX)
   - 弹孔贴花 (Bullet hole decals)
   - 子弹轨迹 (Tracer rounds)
   - 每种武器不同射速/伤害/弹匣容量

3. WeaponSwitchSystem
   - 三种武器切换 (手枪/步枪/霰弹枪)
   - 数字键 1/2/3 切换
   - 切换动画播放
   - 切换时短暂无法射击

4. FPSHitSystem
   - 命中判定 (Hit detection)
   - 爆头倍率 (Headshot multiplier, 2x damage)
   - 身体/四肢不同伤害区域
   - 血液飞溅特效 (Blood splatter VFX)

5. EnemyAI
   - 巡逻状态 (Patrol): 在指定路径上巡逻
   - 警戒状态 (Alert): 发现玩家后进入
   - 射击状态 (Engage): 向玩家射击
   - 掩体状态 (Cover): 寻找掩体躲避
   - 状态机切换 (State machine transitions)

6. EnemySpawner
   - 敌人刷新管理
   - 刷新点和刷新数量配置
   - 波次刷新 (可选)

7. BombObjective
   - 炸弹拆除任务
   - 接近后显示交互提示
   - 按住 E 拆除 (有进度条)
   - 拆除完成触发任务成功

8. FPSDamageSystem
   - 玩家受伤
   - 屏幕边缘红色遮罩 (Damage vignette)
   - 生命值管理 (Health management)
   - 死亡处理

9. FPSHUDController
   - 弹药显示 (Ammo count)
   - 血量显示 (Health bar)
   - 任务信息 (Mission info)
   - 与 UI 层交互
