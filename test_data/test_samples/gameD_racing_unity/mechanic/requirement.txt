# Mechanic Generation Requirements - gameD_racing_unity

## Generation Boundary

Generate a new Unity package named `A3GameRacingGameplay`. The existing
`engine_adapters/unity3d/examples/RacingExample` is a structural and runtime
contract reference only. Do not copy its transform-only vehicle controller as
the final implementation. UI code must remain outside this package.

## Required Systems

- `RacingBootstrap`: binds imported assets, grid positions, checkpoints and
  the racing line without hard-coded source paths.
- `ArcadeCarController`: Rigidbody acceleration, braking/reverse, steering,
  handbrake, downforce, ground detection and stable collision.
- `VehicleVisualRig`: discovers optional wheel/steering nodes and drives their
  visual transforms from physics state.
- `DriverPoseRig`: seats the rigged driver and uses procedural hand targets or
  IK when the imported rig supports them.
- `CameraSwitchController`: smooth cockpit-or-hood and chase views switched by
  C without creating multiple active AudioListeners.
- `RaceManager`: Countdown -> Racing -> Finished state machine, three laps,
  timing, position and complete restart.
- `RaceCheckpoint`: accepts only the next checkpoint in order.
- `RacingLine` and `AICarController`: three AI cars follow a closed waypoint
  route and slow for corners.
- `RacingRuntimeAdapter`: exposes normalized input and observable race state to
  A3GameRuntime sessions.

## Physics Rules

- Moving a car only by `Transform.position` is forbidden.
- Every car requires a non-kinematic Rigidbody and stable compound colliders.
- The vehicle must remain grounded on the cleaned track collision surface.
- A fallen, upside-down or out-of-bounds car resets to its latest safe point.
- Player and AI grid positions must not overlap each other or scenery.

## Input

| Action | Input |
|---|---|
| Accelerate | W / positive move_y |
| Brake or reverse | S / negative move_y |
| Steer | A/D / move_x |
| Handbrake | Space |
| Switch camera | C |
| Restart after finish | Enter |

## Runtime Contract

Expose race state, speed in km/h, gear, current/total lap, next checkpoint,
current/best lap time, position, racer count and camera mode. Publish state
changes for the separate UI package and runtime-session snapshots.

## Output

Write package source, asmdef, package manifest, mechanic contract, focused
tests and context trace under the canonical mechanic task directory. Unity
operations are performed only through the public UnityClient API.
