# UI Generation Requirements - gameD_racing_unity

## Generation Boundary

Generate a separate Unity package named `A3GameRacingUI`. Bind only to the
public mechanic contract produced by task `demoRacing_050`; do not place race
physics or checkpoint logic in UI code. `RacingUIExample` is a structural
reference only.

## P0 Screens and State

- `RacingHUD`: digital speed, gear, LAP current/total, current and best time,
  race position and active camera mode.
- `CountdownOverlay`: large stable 3, 2, 1 and GO states.
- `RaceResults`: final position, lap times and restart button.
- Enter and the restart button call the same mechanic restart command.

The HUD must remain readable without overlap at 1920x1080 and 1280x720.
Use a stable landscape layout and keep result UI inactive during the race.

## P1

A circular speedometer needle and compact track minimap are desirable but must
not block P0 completion.

## Output

Write UI source, asmdef, package manifest, binding manifest, tests, mechanic
contract fixture and context trace under the canonical UI task directory.
