# gameForge_fps_ue — Game Design Brief

## Page 1: Concept & Gameplay

### Game Vision
gameForge_fps_ue is a first-person tactical shooter built on Unreal Engine 5,
inspired by Call of Duty. The player is a counter-terrorism operative clearing
an abandoned prison occupied by terrorists. Armed with a generated shotgun,
the player must eliminate all enemies to complete the mission.

### Core Gameplay Loop
Launch → Spawn → Explore Prison → Find Enemies → Combat → Clear Area →
Mission Complete → Restart

### Camera & Perspective
First-person perspective. Mouse controls view (pitch + yaw). Weapon model
visible in lower-right of view. One hand on pistol grip, one hand on foregrip/
stock position.

### Characters

**Player — Counter-Terrorism Operative (反恐特战)**
Wears tactical vest and counter-terrorism gear. First-person view shows only
hands and weapon. Hands positioned realistically: rear hand on pistol grip,
front hand on foregrip/stock area.

**Enemy — Terrorist (恐怖分子)**
Dressed in all black clothing. Carries a rifle. Patrols the prison, engages
on detecting the player. Has idle, walk, shoot, hit reaction, and death
animations.

### Weapon
Generated shotgun (霰弹枪) — pump-action, tactical black finish, high-detail PBR.
6 shells per magazine. Pellet spread: 6-8 pellets per shot. High close-range
damage with distance falloff. Fire rate ~1 shot/second.

### Combat System
- **Player Health**: 100 HP, regenerates after 3s without damage
- **Shotgun**: 15 damage per pellet body, 30 per pellet headshot
- **Enemy Rifle**: 8 damage per hit, fires every 1.5s
- **Headshot**: 2x damage multiplier
- **Damage Vignette**: Red screen edge when taking damage

### Scene
Imported open-source abandoned prison map. Indoor corridors, cell blocks, open
common areas. Dark, atmospheric lighting. Doors that can be opened. Concrete
and metal materials with realistic wear.

## Page 2: Technical & Production

### Engine & Architecture
- **Engine**: Unreal Engine 5
- **Code Module**: FPSGameplay (Blueprints or C++)
- **UI Module**: FPSGameUI (UMG widgets)

### AI Asset Generation Pipeline
1. **3D Objects**: Meshy API → shotgun model, terrorist character model
2. **Motions**: MoMask → BVH → retarget → enemy animation FBX (5 clips)
3. **Player hand motions**: MoMask → BVH → retarget → hand animation FBX (3 clips)
4. **Scene**: Imported open-source abandoned prison map
5. **Audio**: Seed Audio API → gunfire SFX, environment ambience

### Game Mechanics (7 Systems)
1. FPSPlayerController — movement, look, crouch, sprint
2. WeaponSystem — shotgun firing, spread, reload, recoil
3. FPSHitSystem — pellet raycast, damage zones, headshot multiplier
4. EnemyAI — patrol, detect, engage, cover state machine
5. EnemySpawner — enemy placement and tracking
6. FPSDamageSystem — player health, regen, damage vignette
7. FPSHUDController — crosshair, ammo, health, objective, kill feed

### UI Design
- Crosshair with shotgun spread indicator (expands on move)
- Ammo counter (bottom-right)
- Health vignette (screen-edge red)
- Objective text (top-left)
- Kill notification (center pop-up)
- Mission complete / game over screen

### Acceptance Criteria (14 checks)

### MVP Playable Loop
