# UI Generation Requirements — gameC_fps_tactical_ue

## Overview
Generate the complete in-game UI for the UE5 first-person tactical shooter.
The UI receives the finalized Mechanic artifact, game design document, and
engine context. Output is engine-native UE5 UMG widgets.

## Engine
- **Engine**: Unreal Engine 5
- **UI Target**: engine_runtime (UE5 UMG widgets)
- **Module Name**: FPSGameUI

## UI Screens

### 1. FPSHUD (Main In-Game HUD)

#### Crosshair
- **Position**: Center of screen
- **Design**: Shotgun spread indicator — four lines expanding/contracting based on movement and fire state
- **Behavior**: Expands when moving, contracts when still
- **Color**: White, turns red when aiming at enemy

#### Ammo Counter
- **Position**: Bottom-right of screen
- **Content**: "shells in magazine / reserve ammo"
- **Behavior**: Updates on fire and reload
- **Color**: White normally, red when magazine empty

#### Health Indicator
- **Position**: Screen-edge red vignette overlay
- **Behavior**: Intensifies as health decreases
- **Visual**: Red translucent gradient from screen edges inward
- **Regeneration**: Fades out when health regenerates

#### Objective Display
- **Position**: Top-left of screen
- **Content**: "Eliminate all enemies"
- **Behavior**: Updates when enemies remaining changes

#### Kill Notification
- **Position**: Center of screen, brief pop-up
- **Content**: "KILL +100"
- **Behavior**: Appears for 2 seconds then fades

#### Mini-map (optional)
- **Position**: Top-right corner
- **Content**: Simplified top-down view showing player and enemy positions

### 2. GameOverScreen
- Full-screen overlay
- "MISSION COMPLETE" (if won) or "YOU DIED" (if lost)
- Stats: enemies killed, time survived
- "Press ENTER to Restart" prompt
- "Press ESC to Quit" prompt

## State Bindings
- player_health — current HP (0-100)
- player_max_health — max HP (100)
- shotgun_ammo — shells in magazine (0-6)
- shotgun_reserve — reserve shells
- is_reloading — true during reload
- is_moving — true when player moves
- is_sprinting — true when sprinting
- enemies_remaining — alive enemy count
- enemies_killed — total killed
- game_state — "playing", "mission_complete", "game_over"
- damage_vignette — vignette intensity (0-1)

## Event Bindings
- on_player_damaged — trigger red vignette
- on_enemy_spawned — update enemies remaining
- on_enemy_killed — show kill notification, update counter
- on_weapon_fired — update ammo, muzzle flash
- on_weapon_reload — show reload state
- on_mission_complete — show game over screen (win)
- on_player_died — show game over screen (loss)
- on_state_changed — update UI state

## Command Bindings
- shoot — fire weapon
- reload — reload weapon
- interact — open doors
- reset_game — restart mission

## Viewports
- 1920×1080 (primary, 16:9 landscape)
- 1280×720 (secondary)

## Acceptance Criteria
- Crosshair visible, expands when moving
- Crosshair turns red when aiming at enemy
- Ammo count updates on fire and reload
- Health vignette appears when taking damage
- Objective text visible and updates
- Kill notification appears on enemy kill
- Mission complete screen shows on win
- Game over screen shows on death
- "Press ENTER to Restart" appears on end screen
- Restart resets all UI elements

## Forbidden UI
- No 3D world-space UI (all screen-space)
- No mobile touch controls
- No microtransactions
