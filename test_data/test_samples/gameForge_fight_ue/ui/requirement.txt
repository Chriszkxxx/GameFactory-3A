# UI Generation Requirements — gameForge_fight_ue

## Overview
Generate the complete in-game UI for the UE5 one-on-one fighting game. The UI
receives the finalized Mechanic artifact (gameplay contract), the game design
document, and engine context. The output is engine-native UE5 UMG widgets.

## Engine
- **Engine**: Unreal Engine 5
- **UI Target**: engine_runtime (UE5 UMG widgets)
- **Module Name**: FightArenaUI

## UI Screens

### 1. FightHUD (Main In-Game HUD)

#### HP Bars
- **Position**: Top-left (P1) and top-right (P2) of the screen
- **Design**: Horizontal bar with character portrait on the outer edge
- **Behavior**: Depletes as HP decreases
- **Visual feedback**: Flashes white briefly when the character takes damage
- **Color**: P1 = warm red/orange, P2 = cool blue/purple

#### Ultimate Energy Bar
- **Position**: Directly below each HP bar
- **Design**: Thinner horizontal bar, segmented (10 segments)
- **Behavior**: Fills from 0% to 100% as energy accumulates from landed punches
- **Visual feedback**: Glows when 100% full, pulsing animation

#### Round Indicator
- **Position**: Center top of screen below the timer
- **Content**: current round and P1/P2 round-win score
- **Round pips**: Two small markers per player (best of 3, first to 2)
- **Transitions**: "FIGHT!" (large, animated, fades out), "K.O." (dramatic)

#### Timer
- **Position**: Center top as the dominant center number
- **Content**: Large countdown number from 99 to 0
- **Behavior**: Turns red when ≤10 seconds remaining

#### Character Name Plates
- **Position**: Above each HP bar
- **Content**: "WARRIOR" / "GODDESS"
- **Style**: Bold font with drop shadow

### 2. RoundTransition
- Full-screen overlay between rounds
- Shows round number ("ROUND 2") with entrance animation
- "FIGHT!" trigger
- Fades to reveal the FightHUD

### 3. MatchEnd
- Full-screen overlay when match concludes
- Shows winner character name
- "YOU WIN" / "YOU LOSE" text
- "Press ENTER to Restart" prompt
- "Press ESC to Quit" prompt

### 4. UltimateOverlay
- Brief screen effect when ultimate activates
- Fire VFX overlay (orange-red tint)
- Screen shake on ultimate impact
- Duration: 1-2 seconds

## State Bindings
- P1_HP, P2_HP — health points (0-100)
- P1_Energy, P2_Energy — ultimate energy (0-100)
- Round_Number — current round (1, 2, 3)
- Timer_Remaining — seconds left (0-99)
- P1_Round_Wins, P2_Round_Wins — rounds won (0-1)
- Match_State — "fighting", "round_end", "match_end"
- P1_State, P2_State — character state ("idle", "attacking", "blocking", "hit", "ultimate")

## Event Bindings
- OnDamageTaken(player, amount) — trigger HP bar flash
- OnEnergyChanged(player, amount) — update energy bar
- OnRoundStart(round_number) — show round indicator
- OnFightStart() — show "FIGHT!" text
- OnKO(loser) — show "K.O." text
- OnRoundEnd(winner) — show round transition
- OnMatchEnd(winner) — show match end screen
- OnUltimateActivated(player) — show ultimate overlay
- OnTimerTick(remaining) — update timer display

## Command Bindings
- RestartMatch() — restart from round 1
- QuitGame() — exit application

## Viewports
- 1920×1080 (primary, 16:9 landscape)
- 1280×720 (secondary)

## Acceptance Criteria
- HP bars visible and update in real time
- HP bars flash white when character takes damage
- Energy bars fill during combat and highlight when full
- Timer counts down from 99 and turns red at ≤10 seconds
- Round indicator shows correct round number
- "FIGHT!" text appears at round start
- "K.O." text appears on knockout
- Character name plates visible above HP bars
- Round win pips update correctly
- Ultimate overlay triggers on ultimate activation
- Match end screen shows winner
- "Press ENTER to Restart" appears on match end
- Restart resets all UI elements

## Forbidden UI
- No 3D world-space UI (all UI must be screen-space)
- No mobile touch controls
- No microtransactions or store UI
