================================================================================
 Game Design Brief — gameE_fps_tactical (FPS 战术射击)
 2-Page Game Design Document
================================================================================

PAGE 1: GAME OVERVIEW & CORE LOOP
--------------------------------------------------------------------------------

Title: FPS Tactical — Counter-Terrorism Operation
Genre: First-Person Tactical Shooter
Engine: Unity3D 2022.3 URP
Visual Reference: Call of Duty (使命召唤)
Platform: PC (Windows)

1.1 Premise
  The player takes on the role of a counter-terrorism operator deployed to
  an urban combat zone. The mission: sweep the area, eliminate all enemy
  combatants, locate the bomb, and defuse it before time runs out.

1.2 Camera & Perspective
  First-person camera. Weapon model visible in lower-right of the view.
  Camera head-bob during movement. Aim-down-sights (ADS) zooms and tightens
  the crosshair when right mouse button is held.

1.3 Core Gameplay Loop
  Spawn → Navigate urban environment → Engage enemies → Clear area →
  Locate bomb → Defuse (hold E) → Mission Complete

  Every node in this loop must have a verifiable pass condition. If any node
  breaks, the pipeline reports failure and triggers self-repair.

1.4 Weapons (3 types)
  | Weapon  | Slot | Damage | Fire Rate | Mag Size | Range  | Notes        |
  |---------|------|--------|-----------|----------|--------|--------------|
  | Pistol  | 1    | 25     | Semi      | 12       | Medium | Sidearm      |
  | Rifle   | 2    | 35     | Auto      | 30       | Long   | Primary      |
  | Shotgun | 3    | 60     | Pump      | 6        | Short  | Close range  |

  Headshots deal 2x damage. Each weapon has unique recoil, reload time,
  and first-person hand animations.

1.5 Enemies (Terrorist Fighters)
  - AI states: Patrol → Alert → Engage → Cover → Dead
  - Patrol: Walk along designated waypoints
  - Alert: Detect player via line-of-sight, enter combat
  - Engage: Fire at player, reposition
  - Cover: Take cover when health is low
  - Death: Ragdoll or scripted fall (forward/back based on hit direction)

1.6 Mission Structure
  Phase 1: "Eliminate all enemies" — Kill every terrorist in the area
  Phase 2: "Defuse the bomb" — Approach the bomb, hold E to defuse
  Success: Bomb defused → "MISSION COMPLETE"
  Failure: Player dies → "MISSION FAILED" → Restart

PAGE 2: CONTROLS, UI, ASSETS & ACCEPTANCE
--------------------------------------------------------------------------------

2.1 Controls
  | Action            | Key           |
  |-------------------|---------------|
  | Move              | WASD          |
  | Sprint            | Shift         |
  | Jump               | Space         |
  | Crouch            | Ctrl          |
  | Fire              | Mouse Left    |
  | Aim (ADS)         | Mouse Right   |
  | Reload            | R             |
  | Switch Weapon     | 1 / 2 / 3     |
  | Interact / Defuse | E (hold)      |
  | Throw Grenade     | G             |

2.2 UI / HUD
  - Crosshair: Center screen, dynamic spread (expands on move/fire,
    tightens on aim)
  - Ammo: Bottom-right "mag / reserve", flashes red when low
  - Health: Bottom-left bar + red screen-edge vignette when damaged
  - Weapon Slots: Bottom-center, 3 icons, current highlighted
  - Mission Info: Top-left objective text + enemy counter
  - Kill Notification: Center "KILL +100" / "HEADSHOT +200", fades out
  - Defuse Progress: Radial/linear bar when holding E near bomb

2.3 Scene
  Urban warfare environment:
  - Main street with brick/concrete buildings on both sides
  - Narrow alley branching off (flanking route, cover)
  - Enterable warehouse (interior combat space)
  - Props: roadblocks, barbed wire, sandbags, abandoned cars
  - Daytime lighting with shadow contrast
  - Realistic damaged/dirty materials

2.4 Audio
  - Weapon SFX: pistol/rifle/shotgun gunfire (distinct per weapon)
  - Explosion SFX: grenade/C4 detonation with shockwave
  - Radio dialogue (Chinese TTS):
    • Mission start briefing
    • Bomb spotted callout
    • Mission complete confirmation
  - Ambient: urban environment ambience (wind, distant city sounds)

2.5 Asset Pipeline
  1. T-pose image → 3D model (terrorist character)
  2. 3D objects (3 weapons, terrorist, bomb, ammo crate)
  3. Motions (7 enemy + 9 player hand animations)
  4. Scene (urban warfare)
  5. Audio (gunfire, explosion, radio dialogue)
  6. Mechanic code (9 C# systems)
  7. UI code (HUD with 7 elements)
  8. Unity assembly (import assets + compile + build scene)
  9. Build & run
  10. CG video (CG-3 counter-terrorism warehouse, 25s)

2.6 Minimum Viable Playable Loop (MVP)
  Launch → Spawn with weapon → Move (WASD) → Fire (LMB) → Hit enemy →
  Enemy dies → Find bomb → Hold E → Defuse complete → Mission Complete

  If any step fails, the self-repair loop triggers (max 3 attempts per
  stage). The pipeline tracks repair history and reports final status.

2.7 Acceptance Categories
  - Launch: Unity launches, scene loads, player spawns, weapon visible
  - Movement: WASD, sprint, jump, mouse look
  - Weapon System: Fire, muzzle flash, bullet holes, reload, switch (1/2/3)
  - Combat: Damage, headshot bonus, hit reaction, death animation, blood VFX
  - Enemies: Spawn, patrol, detect, shoot, take damage
  - Objective: Mission text, bomb interact, defuse progress, mission success
  - UI: Crosshair, ammo, health, weapon slots, kill notification, defuse bar
