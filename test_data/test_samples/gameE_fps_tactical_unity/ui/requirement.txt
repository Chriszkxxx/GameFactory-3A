================================================================================
 UI Generation Requirements — gameE_fps_tactical_unity
================================================================================

生成方式: LLM Agent 调用 Unity tools 生成 UI 代码
引擎: Unity3D 2022.3 URP
交付模式: engine_native (引擎原生 UI + Browser Play)
输出: UI 源码 + UI 测试 + 绑定清单 + 截图计划

--------------------------------------------------------------------------------
 UI 元素清单 (UI Element List)
--------------------------------------------------------------------------------

1. 准星 (Crosshair)
   - 屏幕中央十字准星
   - 移动/奔跑时扩散 (动态扩张)
   - 射击时短暂扩散
   - 瞄准时收紧

2. 弹药显示 (Ammo Counter)
   - 右下角显示 "当前弹匣 / 总弹药"
   - 换弹时闪烁提示
   - 弹药耗尽时红色警告

3. 血量显示 (Health Indicator)
   - 左下角血量条
   - 受伤时屏幕边缘红色遮罩 (Damage vignette)
   - 低血量时持续红色脉冲

4. 武器栏 (Weapon Wheel / Slots)
   - 底部显示三种武器图标 (手枪/步枪/霰弹枪)
   - 当前选中武器高亮
   - 切换时短暂动画

5. 任务信息 (Mission Info)
   - 左上角显示当前任务目标
   - "消灭所有敌人" (Eliminate all enemies)
   - "拆除炸弹" (Defuse the bomb)
   - 剩余敌人数量

6. 击杀提示 (Kill Notification)
   - 击杀时屏幕中央显示 "KILL +100"
   - 短暂显示后淡出
   - 爆头时显示 "HEADSHOT +200"

7. 炸弹拆除进度 (Defuse Progress Bar)
   - 接近炸弹时显示交互提示 "按住 E 拆除"
   - 按住 E 时显示进度条 (0% - 100%)
   - 拆除完成显示 "BOMB DEFUSED"

--------------------------------------------------------------------------------
 视口与分辨率 (Viewports)
--------------------------------------------------------------------------------
  - 主视口: 1920×1080 (16:9, 横屏)
  - UI 缩放模式: Scale With Screen Size
  - 参考分辨率: 1920×1080

--------------------------------------------------------------------------------
 验收标准 (Acceptance Criteria)
--------------------------------------------------------------------------------
  - crosshair_visible: 准星可见
  - crosshair_expands_on_move: 移动时准星扩散
  - ammo_count_updates: 弹药数实时更新
  - ammo_low_warning: 弹药低时红色警告
  - health_bar_updates: 血量条实时更新
  - damage_vignette: 受伤时红色遮罩
  - weapon_slots_display: 武器栏显示三种武器
  - weapon_highlight_current: 当前武器高亮
  - mission_info_display: 任务信息显示
  - kill_notification_appears: 击杀提示出现
  - defuse_prompt_shown: 接近炸弹显示拆除提示
  - defuse_progress_bar: 按住 E 显示进度条
